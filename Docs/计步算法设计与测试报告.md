## 1. 算法设计

### 1.1 设计目标

设计一套能够**精准识别真实步行动作、剔除日常行为噪声干扰**的计步算法。具体要求：

| 要求 | 说明 |
|------|------|
| 准确性 | 以 MAE / MAPE 为核心指标，标签为文件名标注的步数 |
| 实时性 | 1 秒为单位滑动处理，适配嵌入式平台 |
| 抗干扰 | 能够区分走路/跑步与切菜、刷牙、挥手等日常动作 |
| 可移植 | C 语言实现，单精度浮点，固定大小静态缓冲区 |

### 1.2 算法流程

```
┌──────────────────────────────────────────────────────────┐
│                    IMU 原始数据输入                         │
│            (ax, ay, az, gx, gy, gz) × N                  │
└────────────┬─────────────────┬───────────────────────────┘
             │                 │
       ┌─────▼──────┐    ┌─────▼──────┐
       │ 1.陀螺仪模值 │    │ 2.加速度模值  │
       │ |g|=√(x²+y²+z²)│  │ |a|=√(x²+y²+z²)│
       └─────┬──────┘    └─────┬──────┘
             │                 │
       ┌─────▼──────┐          │
       │ 3.均值滤波   │          │
       │ (w=25, 0.5s)│          │
       └─────┬──────┘          │
             │                 │
       ┌─────▼────────────────▼──────┐
       │ Gate A — 静止检测             │
       │ gyr_mean < 300 → return 0    │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ Gate B — 陀螺主导检测         │
       │ gyr_std > 5×acc_raw_std     │
       │ → return 0                  │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ 4.原始峰值密度预过滤           │
       │ raw_density > 0.12          │
       │ → return 0 (len > 500)      │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ 5.自适应区间阈值              │
       │ gyr < 600: walk (15~60)    │
       │ gyr 600~1200: brisk (13~45)│
       │ gyr ≥ 1200: run (10~35)    │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ 6.DC 移除 + 均值滤波(w=7)     │
       └─────────────┬───────────────┘
                     │

       │ acc_std < 120 &&            │
       │ gyr_mean < 600 → return 0  │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ 7.峰值检测 + 谷值检测          │
       │ (above/below mean)          │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ 8.合并邻近峰（无谷间隔）        │
       │ 9.Chain-Restart区间滤波       │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ Gate D — 峰幅门控             │
       │ peak_ampl < 200 &&          │
       │ gyr < GYR_LOW+200 → ret 0  │
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐

       │ (walk/brisk 仅当 gyr_cv>0.75)│
       └─────────────┬───────────────┘
                     │
       ┌─────────────▼───────────────┐
       │ 11.软周期性惩罚               │
       │ CV > cv_limit → penalty²   │

                     │
              ┌──────▼──────┐
              │  步数输出     │
              └─────────────┘
```

### 1.3 核心创新

| 创新点 | 原始算法 | 改进算法 |
|--------|----------|----------|
| **信号源** | X/Y/Z 三轴独立处理 | 加速度模值（姿态无关） |
| **轴融合** | 取三轴峰值计数的中位数 ×2 | 单通道直接计数 |
| **噪声过滤** | 无（所有活动同等对待） | 陀螺仪 5 级活动分类门控 + 原始峰值密度预过滤 |
| **节律验证** | 无 | 峰值间隔 CV 周期性检验 + 陀螺 CV 软惩罚 |
| **阈值设定** | 硬编码（`ACC_GRAVITY/10`） | 自适应 + 多级门控 |
| **数据利用** | 仅加速度 | 加速度 + 陀螺仪 |

| 参数 | 数值 | 说明 |
|------|------|------|
| `MEAN_WIN` | 7 | 加速度均值滤波窗口（0.14s @ 50Hz） |

| `GYR_STATIONARY` | 300 | 陀螺仪静止阈值 |

## 2. 算法详解

### 2.1 加速度模值计算

使用三轴加速度的欧几里得范数，消除设备佩戴方向的影响：

```
acc_mag[i] = sqrt(ax[i]² + ay[i]² + az[i]²)
```

**优势**：无论手环/手表如何旋转，步行产生的整体加速度变化幅度是一致的。

### 2.2 信号滤波

采用两级处理：

1. **DC 移除**：减去全信号均值，消除重力分量（~4096 LSB = 1G）
2. **均值滤波**：7 样本对称滑动窗口，平滑高频噪声

```
acc_dc[i] = acc_mag[i] - mean(acc_mag)
acc_filt[i] = moving_average(acc_dc, window=7)
```

选择 7 样本窗口的理由：在 50Hz 采样率下，7 样本 ≈ 0.14s，能有效滤除 7Hz 以上噪声，
同时保留 0.5-3Hz 的步行主频成分。

### 2.3 峰值检测

```
1. 找到所有局部极大值（signal[i] ≥ signal[i-1] 且 signal[i] > signal[i+1]）且高于均值线
2. 找到所有局部极小值（signal[i] ≤ signal[i-1] 且 signal[i] < signal[i+1]）且低于均值线
3. 合并无谷间隔的相邻峰（保留幅度更高的那个）
4. Chain-Restart 区间滤波：
   - 间距 ∈ [min_dist, max_dist] 的峰保留
   - 间距 > max_dist 时重启计数链（避免因一次中断丢失后续所有步数）
   - 间距 < min_dist 时丢弃（去重）
```

区间约束根据陀螺仪活动水平自适应调整：

| 活动水平 | gyr_mean 范围 | min_dist | max_dist | 步频范围 |
|---------|--------------|----------|----------|---------|
| 走路 | < 600 | 15 (0.3s) | 60 (1.2s) | 0.83~3.3 Hz |
| 快走 | 600~1200 | 13 (0.26s) | 45 (0.9s) | 1.1~3.8 Hz |
| 跑步 | ≥ 1200 | 10 (0.2s) | 35 (0.7s) | 1.4~5.0 Hz |

### 2.4 活动分类门控

使用多级门控，逐级过滤非步行活动：

```
Gate A — 静止检测
  条件：gyr_mean < 300
  含义：陀螺仪均值极低 → 设备静止或极微弱运动
  动作：直接返回 0

Gate B — 陀螺主导检测
  条件：gyr_std > 5.0 × acc_raw_std
  含义：手臂大幅度摆动但身体加速度变化小 → 挥手等非步行动作
  动作：直接返回 0

原始峰值密度预过滤
  条件：len > 500（>10s）且 DC 移除后未滤波信号的峰值密度 > 0.12
  含义：DC 移除后峰值仍然密集 → 高频噪声（如抖动、切菜）
  动作：直接返回 0

Gate C — 微弱运动检测
  条件：滤波后加速度标准差 acc_std < 120 且 gyr_mean < 600
  含义：加速度波动小且陀螺仪活动低 → 切菜、刷牙等细微动作
  动作：直接返回 0

Gate D — 峰幅检测
  条件：peak_ampl < 200 且 gyr_mean < GYR_LOW_ACTIVE + 200 (= 800)
  含义：峰值幅度过低 → 不足以构成步行冲击
  动作：直接返回 0
```

### 2.5 陀螺仪 CV 软惩罚

在走路/快走模式下（gyr_mean < 1200），如果平滑后陀螺仪信号的变异系数 `gyr_cv > 0.75`，
说明陀螺仪信号本身不规则，可能是非步态的周期性噪声（如快速剁菜有节律但 gyro 波动大）。
此时按比例 `0.75 / gyr_cv` 软惩罚步数，而非完全归零：

```
if gyr_mean < GYR_HIGH_ACTIVE and gyr_cv > GYR_CV_SOFT:
    steps = steps × clamp(GYR_CV_SOFT / gyr_cv, 0, 1)
```

跑步模式不受此惩罚，因为跑步时陀螺仪 SV 天然较大。

### 2.6 周期性验证

步行是一种节律性运动，峰值间隔相对均匀。用变异系数（CV = std/mean）度量。
当步数 ≥ 3 时才执行此检查：

| 陀螺仪活动水平 | 要求的 CV 上限 | 说明 |
|---------------|---------------|------|
| 走路（< 600）   | 0.55（严格） | 步行节律稳定 |
| 快走/跑步（≥ 600） | 0.85（宽松） | 跑步步频变化允许更大 |

如果 CV 超过阈值，应用二次惩罚因子 `(cv_limit / cv)²`，使步数呈非线性衰减。
跑步采用更宽松的 CV 上限，因为跑步时的步频变化比走路大。

## 5. 复杂度分析

### 时间复杂度

设输入样本数为 N。

| 步骤 | 复杂度 | 说明 |
|------|--------|------|
| 加速度/陀螺仪模值 | O(N) | 逐样本平方和开方 |
| 均值滤波 | O(N·w) | 滑动窗口，w=7 或 25 |
| 峰值检测 | O(N) | 单次遍历 |
| 合并邻近峰 | O(P·V) | P=峰值数, V=谷值数, 最坏 O(N²) |
| 区间约束 | O(P) | 单次遍历 |
| 门控与周期性 | O(P) | 统计计算 |
| **总体** | **O(N·w + P·V)** | 实际远小于 N²（P, V ≪ N） |

典型 30 秒数据（1500 样本）：P ≈ 50，V ≈ 50，运算量极小，远超实时。

### 空间复杂度

| 缓冲区 | 大小 | 说明 |
|--------|------|------|
| acc_mag_buf | 195 KB (float[N]) | 加速度模值 |
| acc_filt_buf | 195 KB | 滤波后加速度 |
| gyr_mag_buf | 195 KB | 陀螺仪模值 |
| gyr_smooth_buf | 195 KB | 平滑后陀螺仪 |
| acc_tmp | 195 KB | 临时工作区 |
| gyr_tmp | 195 KB | 临时工作区 |
| peak_idx | 10 KB (uint16_t[5000]) | 峰值索引 |
| valley_idx | 10 KB | 谷值索引 |
| intervals_buf | 10 KB (int16_t[5000]) | 间隔缓冲 |
| **合计** | **~1.2 MB** | |

> **注意**：以上为测试版全量缓冲区（支持 50000 样本 = 1000 秒）。实际嵌入式部署时，可缩减至滑动窗口模式（仅存储 5~10 秒数据），内存占用可降至 ~30 KB。

## 6. 已知局限与改进方向

### 当前局限

1. **周期性节律活动误判**：部分干扰动作（如快速剁菜、有节律的挥手）在加速度和陀螺仪上都表现出与步行相似的节律模式，导致误检（当前 FP 率 19.6%）。
2. **极端慢走/快跑**：步频超出自适应区间范围（0.83~5.0Hz 外）时会被区间约束过滤。
3. **固定阈值**：部分门控阈值（如 `GYR_ACC_RATIO=5.0`、`GYR_STATIONARY=300`）未针对不同佩戴位置自适应。

### 改进方向

1. **频谱分析**：利用 NMSIS DSP 库的 FFT 提取主频特征，步行主频集中在 1~2.5Hz。
2. **机器学习分类**：参考提供的 BP 神经网络示例，训练步行/非步行二分类器。
3. **自适应标定**：前几秒数据用于自动标定步频范围和阈值。
