4.       使用手册
    VeriHealthi QEMU SDK 是 VeriHealthi Embedded SDK 的 QEMU 版本分支，两者支持相同
     的 OS 接口和功能，是一种基于 Nuclei Studio IDE 的、不依赖硬件的软件开发工具包，支持
     直接在 IDE 运行。
        推荐在 Windows 10 及以上的操作系统使用 Nuclei Studio IDE 2024.02 进行开发，Nucl
         ei Studio IDE 下载地址：https://download.nucleisys.com/upload/files/nucleistudio/Nucle
         iStudio_IDE_202402_DEV-win64.zip。
        QEMU 版本包含支持跟 SoC 相同的 CPU，系统 timer，RAM 和保存及运行代码用的 flas
         h 空间（不支持 flash 读写，只支持代码执行），不支持 I2C/SPI/DMA/WDT/ADC/DAC/I2
         S/PDM/CRC 等硬件接口。
        VeriHealthi QEMU SDK 工程需解压 VeriHealthi_QEMU_SDK_v3.7.zip，解压后将工程
         导入到 Nuclei Studio IDE 中，具体步骤及软件使用方法请参考 VeriHealthi Embedded
         SDK 开发手册-VESC2026-V2.0.pdf，SDK 接口文档最新版本请通过大赛官网访问 https://
         vesc.verisilicon.com/sdk/Embedded/index.html。
    VeriHealthi_IMU_Dataset.zip 压缩包包含了算法的 IMU 数据集，用于算法的训练和测试，具
     体使用方法请参考 VeriHealthi 算法开发手册-VESC2026-V1.0.pdf。

5.     已知问题与限制
    VeriHealthi QEMU SDK 仅用于 QEMU 平台，不能用于实际硬件平台，基于 QEMU SDK 开
     发的软件将来可以导入到 VeriHealthi Embedded SDK，实现在实际硬件平台上运行。
    VeriHealthi QEMU SDK 不支持 fopen，请通过 const 数组的方式导入数据。
    VeriHealthi QEMU SDK RAM 空间有限，添加大数组的时候需要加上 const 属性将数组分配
     到 Flash 空间。
    大赛平台的 SoC 包含了单精度 FPU，使用 double 类型会降低运算效率，请尽量使用 float 类
     型。
